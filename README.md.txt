# Computerized Tax Evaluation System

## Overview

This application is designed to assist with tax evaluation for civil servants.

## Features

* Register civil servants.
* Enter salary information and applicable deductions or reliefs.
* Calculate taxable income.
* Calculate annual tax liability and monthly PAYE.
* Save and view tax evaluation records.

## Requirements

* Python
* Packages listed in requirements.txt

## How to Run

1. Extract the project ZIP file.
2. Open the extracted project folder.
3. Double-click run_app.bat.
4. Wait for the application to start.
5. Open the local address displayed in the terminal, usually http://localhost:8501.

## Database

The application uses tax_system.db to store tax evaluation records. Keep this file in the project folder.

## Important Note

Verify tax calculations against the applicable tax legislation before using the results for official tax decisions.
